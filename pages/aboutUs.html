Automato

An intuitive web app for creating and testing final state automata.

Project Overview

Automato is a web application designed to make the creation and simulation of finite automata simple and intuitive. The first focus of the project is on acceptor automata. Users can visually design automata, simulate their behavior and directly test their solutions.

To allow access to personal projects from any device, the platform supports both anonymous usage and optional user accounts. In addition, Automato provides a set of interactive exercises for designing and analyzing automata, helping students immediately apply and practice newly learned concepts.

A global leaderboard compares users based on different criteria such as the number of states, solution complexity and the time needed to solve exercises.
