# Automato

An intuitive web app for creating and testing final state automata.

## Creators

By: Caspar Börner, Mikhail Iomdin, Thomas Le, Alexander Levant, Yan Rybalchenko, Daniil Yatsiuta

Heinrich-Hertz-Gymnasium Berlin, 2026

## Description

Wir wollen eine Web-Applikation entwickeln, wo intuitiver Entwurf und Simulation endlicher Automaten (zunächst Akzeptoren) möglich ist. Damit man auf seine aktuellen Ergebnisse von jedem Gerät Zugriff hat, soll neben dem anonymen Nutzen eine Anmeldung möglich sein.
Die Web-App beinhaltet zudem verschiedene Übungen zum Entwurf und zur Analyse von Akzeptoren, sodass man direkt das neue Konzept praktisch umsetzen und üben kann. Weiter wird ein Leaderboard erstellt, bei dem man seine aktuellen Ergebnisse bei den Übungen mit anderen Benutzern vergleichen kann (mögliche Kriterien sind Anzahl der Zustände, Komplexität, gebrauchte Zeit für die Lösung).
